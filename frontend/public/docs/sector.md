# sector — 종목·ETF 유니버스 (섹션별 매핑)

`sellbuy.md` 분석 프로그램에 넣을 **예시 유니버스**를 섹션(코어·자산배분·팩터·수급 테마)별로
종목·ETF 코드와 함께 정리한 문서. 개발 시 `universe` 테이블의 시드로 사용한다.

> **투자 권유가 아니다.** 프로그램에 넣을 분석 대상 목록일 뿐이다.
> 종목코드는 안정적이지만, **ETF는 이름·티커가 자주 바뀌고 신규 상장·합병·상장폐지가
> 잦으니 구현 시점에 반드시 재확인**할 것. 표기: ✅ = 검색으로 확인, ⚠️ = 재확인 필요.

## ⑤ 반도체 소부장 심화 (전공정 · 후공정 · MLCC)

**소부장 = 소재·부품·장비.** 반도체 제조는 크게 **전공정**(웨이퍼 위에 회로를 만드는 단계)과
**후공정**(완성된 웨이퍼를 자르고·쌓고·검사해 칩으로 만드는 단계)으로 나뉜다.
2025~2026 국장에서 **HBM·AI 붐**으로 소부장은 수급이 가장 강하게 몰리는 테마다.
(아래 종목코드는 검색으로 확인, ⚠️만 재확인 필요)

## ⑧ 지주사·지배구조 — 자회사(반도체) 가치 연동 · 배당 재분배

지주회사는 **자회사 지분을 보유**하고, 자회사에서 받은 **배당수입을 다시 주주에게 환원**하는
구조다. 그래서 지주사 주가는 **보유 순자산가치(NAV) 대비 할인율**로 평가된다. 자회사(특히
반도체) 주가가 오르면 지주사 NAV가 커지고, **밸류업·자사주 소각으로 할인율이 줄면 지주사가
자회사보다 더 오르기도** 한다(대표 사례: SK스퀘어).

### 8-1. 반도체 주가 상승과 연동되는 지주사

| 지주사 (코드) | 핵심 보유 자산 | 반도체 연동 포인트 |
|---|---|---|
| SK스퀘어 (016360) | **자산의 약 98%가 SK하이닉스 지분** | 하이닉스 '추종 ETF'처럼 움직임. 최근 1년 약 8배 급등, 목표가 상향(110만→270만원). NAV 할인율 65.7%(2024말)→46.4%(2026.3)로 축소 |
| SK (034730) | SK스퀘어·SK이노 등 | 하이닉스 낙수효과로 급등(하루 16%대 상승 사례), '황제주' 등극 |
| 삼성물산 (028260) | 삼성전자·삼성바이오 등 간접 지배 | 삼성 반도체·바이오 가치 연동, 배당수입 확대 |

> **배당 재분배 예시**: SK스퀘어는 **경상 배당수입 일정 비율 + 투자회수 성과 일부를
> 자사주 매입·소각 또는 현금배당**으로 환원. 삼성물산은 2026~2028년 **관계사 배당수입의
> 60~70%를 주주환원**, 최소 DPS 2,500원으로 상향. LG도 최소 배당성향을 크게 올렸다.

### 8-2. 주요 지주사 NAV 할인율 (2026년 기준 참고)

할인율이 **높을수록 저평가**(축소 시 리레이팅 여지), 낮을수록 이미 재평가된 상태.

| 지주사 (코드) | NAV 할인율 | 비고 |
|---|---|---|
| 한화 (000880) | 60.8% | 방산·조선 자회사 |
| SK (034730) | 59.0% | 반도체·에너지 |
| 삼성물산 (028260) | 55.4% | 삼성그룹 지배 축, 주주환원 강화 |
| LG (003550) | 51.0% | 최소 배당성향 상향 |
| SK스퀘어 (016360) | 49.6%(→46.4%, 3월) | 하이닉스 단일 자산, 2028년 30% 이하 목표 |
| CJ (001040) | 11.7% | 이미 낮은 할인 |
| 롯데지주 (004990) | 9.9% | 이미 낮은 할인 |

> 리레이팅 동력: 정부 **밸류업 정책, 상법 개정, 자사주 의무소각, 배당소득 분리과세 확대**.
> 리서치들은 하반기 지주사 탑픽으로 **SK·SK스퀘어·삼성물산**을 제시.

### 8-3. 현대차그룹 지배구조 (순환출자 개편 이슈)

현대차는 국내 대기업 중 거의 유일하게 **순환출자 고리**를 유지한다.

```
현대모비스 → 현대차(22.4%) → 기아(34.5%) → 현대모비스(17.9%) → …(순환)
                └→ 현대제철(6.9%) → 현대모비스(6%) → …(순환)
```

- **문제**: 정의선 회장의 존속 현대모비스 지분이 **7.7%**로 지배력이 불안정.
- **개편 시나리오**: 현대모비스를 '신설(부품·AS)'과 '존속(R&D·현대차 지분 보유)'으로 **분할** →
  존속 모비스 지분을 정 회장이 **매입해 순환출자 고리를 끊고** 지배력 강화.
- **필요 자금**: 지배력 확보·상속에 **약 13조원**(상속세만 약 8조원) 추산.
- **실탄**: 정 회장이 **22.57% 지분을 쥔 보스턴다이내믹스(BD)** 가 상장해 가치가 뛰면,
  상속세 재원·모비스 지분 매입 실탄으로 활용될 전망. → **아틀라스/BD 이슈가 지배구조와 직결**.

관련 종목(코드): 현대차(005380), 기아(000270), 현대모비스(012330), 현대제철(004020 ⚠️),
현대글로비스(086280 ⚠️), 현대차우선주 등. 지배구조 개편·BD 상장은 이들 주가의 공통 재료.

### 8-4. 프로그램 활용 (지주사·지배구조)

- **페어 태깅**: 지주사↔핵심 자회사를 쌍으로 연결(예: SK스퀘어↔SK하이닉스, 삼성물산↔삼성전자).
  자회사 주가 스냅샷과 함께 지주사 **NAV 할인율**을 `stock_context`에 필드로 추적.
- **배당 재분배 필드**: 자회사 배당수입 → 지주사 주주환원(배당성향·자사주 소각률)을 별도 컬럼으로.
- **이벤트 플래그**: 지배구조 개편·분할·BD 상장 같은 **거버넌스 이벤트**를 캘린더로 관리해
  이벤트 전후 주가·수급 반응을 상관분석.

## 프로그램 활용 (개발 항목)

- `universe` 테이블(ticker, name, group, section, note)로 관리하고, 매일 각 종목·ETF의
  시황·수급 스냅샷(`stock_context`)을 채운다.
- **섹터 상관 분석**: 내 40종목이 실제로 몇 개 테마에 몰렸는지 → 과분산·집중도 진단에 연결.
- **코어–새틀라이트 자동 점검**: ①②를 코어(목표 비중), ④를 새틀라이트(비중 상한)로 태깅해
  현재 비중과 목표 비중의 괴리를 리밸런싱 신호로 산출.
- **팩터 벤치마킹**: 내 매매 성과를 ③ 팩터 ETF 수익률과 비교.
- **티커 동기화 루틴**: ⚠️ 표기는 상장폐지·리네이밍 가능 → 실행 시 KRX/운용사(또는 `pykrx`
  ETF 목록 조회)로 최신 코드를 검증·갱신한다.

### universe 시드 스키마 (예시)

```sql
CREATE TABLE universe (
  ticker   TEXT PRIMARY KEY,   -- '005930'
  name     TEXT,               -- '삼성전자'
  kind     TEXT,               -- 'stock' | 'etf'
  section  TEXT,               -- 'core' | 'allocation' | 'factor' | 'theme'
  group_nm TEXT,               -- '반도체' | '고배당' | ...
  verified INTEGER,            -- 1=확인, 0=재확인 필요
  note     TEXT
);
```
