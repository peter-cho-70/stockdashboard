**문서 형식 규칙 (통일)**
1. 모든 문서는 첫머리에 **작성일(또는 기준일/갱신일)** 을 표기한다. 인덱스(`index.html`/`README.md`) 항목에도 일자를 함께 적는다.
2. 점검·조사 리포트는 `doc/report/YYYY-MM-DD-주제.md` 형식으로 저장한다.
3. 새 기능이 완성되면 이 인덱스(`index.html` + `README.md`)에도 항목을 추가하고, GitHub Pages는 `./publish-docs.sh`로 재발행한다.
