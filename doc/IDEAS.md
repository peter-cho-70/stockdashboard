# 아이디어 백로그 (IDEAS)

대화 중 떠오른 순간적인 기능 아이디어를 부담 없이 던져두는 곳입니다.
정식 기획서(`doc/spec/`)를 쓸 정도는 아니지만 잊어버리기엔 아까운 것들을 여기에 한 줄로 적어둡니다.

**진행 방식**
1. 아이디어가 떠오르면 여기 표에 한 줄 추가 (날짜 + 내용 + 왜 필요한지 한 줄).
2. 실제로 만들기로 하면 이 줄을 지우고 [STATUS.md](STATUS.md)의 "진행 중"으로 옮긴다 — 상태를 이중으로 관리하지 않는다.
3. 하다가 필요 없다고 판단되면 그냥 지운다. 여기 남아있다고 언젠가 반드시 만들어야 하는 건 아니다.
