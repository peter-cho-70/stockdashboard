# retire_PRD — 연금·ISA 기반 생애주기 자산관리 · 리밸런싱 모듈 PRD

> 기존 매매·포트폴리오 분석 프로그램(`sellbuy.md`, `sector.md`)에 **추가되는 모듈**의
> 제품 요구사항 문서(PRD). 퇴직연금·ISA 지식 베이스를 담고, 30/40/50대·은퇴 이후
> 생애주기별 자산증식·유지 가이드를 제시하며, 내 포트폴리오를 검토·검증해 리밸런싱한다.
>
> **면책**: 나는 투자·세무 자문가가 아니다. 이 문서의 제도·세제 수치는 조사 시점(2026-07)
> 기준이며 세법 개정으로 바뀔 수 있으니 **구현·활용 전 국세청·금융사 최신 자료로 재확인**한다.
> 이 프로그램은 의사결정을 돕는 도구이지 매매·납입 지시가 아니다.

---

## 1. 개요

### 1.1 배경
기존 프로그램은 "개별 매매 습관 교정(손절·익절)"과 "종목·테마 분석"에 초점이 있었다.
그러나 실제 자산 증식은 **절세 계좌(퇴직연금·ISA)를 활용한 장기 자산배분**이 좌우한다.
포트폴리오 성과의 큰 부분은 종목 선택이 아니라 **자산배분**에서 결정된다는 것이 정설이다.

### 1.2 목적
1. 퇴직연금(DB/DC/IRP)·ISA·연금저축의 **지식 베이스**를 프로그램에 내장.
2. **연령대(30/40/50)·은퇴 이후**에 맞는 자산증식·유지 가이드를 자동 제시.
3. 내 전체 포트폴리오(일반계좌 + 연금 + ISA)를 **검토·검증**하고 **리밸런싱**을 지원.
4. **절세 최적화**(계좌별 자산 배치, 인출 순서)를 규칙으로 제공.

### 1.3 성공 지표(KPI)
- 세액공제 한도 소진율(연 900만원 대비)·ISA 한도 활용률 추적.
- 목표 자산배분 대비 이탈도(드리프트) 축소.
- 은퇴 목표자금 달성 경로(퍼센트) 가시화.
- 계좌 배치 최적화로 예상 절세액 산출.

**목표(In-scope)**
- 제도 지식 베이스, 연령대별 가이드 엔진, 포트폴리오 진단, 리밸런싱 엔진, 절세 배치·인출 순서.
- 기존 `holdings`/`portfolio_metrics`/`universe` 재사용 + 계좌·연금 데이터 확장.

**비목표(Out-of-scope, 초기)**

- 개인 맞춤 세무 신고 대행. 세액공제 "추정"만 제공.
- 국민연금(공적연금) 상세 수급 시뮬레이션(향후 확장 여지).

## 4. 지식 베이스 (제도 정리) — 내장 데이터

### 4.1 퇴직연금 3종

| 구분 | 운용 주체 | 특징 | 세액공제 |
|---|---|---|---|
| **DB형**(확정급여) | 회사가 운용 | 퇴직급여 = 퇴직 전 평균임금×근속. 근로자 운용 부담 없음 | 추가납입 세액공제 **없음** |
| **DC형**(확정기여) | 근로자가 운용 | 회사가 매년 부담금 납입, 근로자가 상품 선택. 성과=본인 책임 | 가입자 추가부담금 세액공제 대상 |
| **IRP**(개인형) | 개인이 운용 | 퇴직금 수령·개인 추가납입 계좌. **위험자산 70% 한도**, 중도인출 엄격 제한 | 세액공제 대상 |

### 4.2 세액공제 (연금저축 + IRP)

- 합산 세액공제 한도: **연 900만원**(연금저축 단독은 600만원, IRP 포함 시 900만원).
- 공제율: 총급여 **5,500만원 이하 16.5%**, 초과 **13.2%**(지방소득세 포함).
  → 900만원 채우면 최대 약 **148.5만원**(16.5%) 환급.
- 합산 납입 한도: 연금저축+DC추가+IRP **연 1,800만원**(이 중 900만원까지만 세액공제).
- 연금 수령 시: 퇴직급여를 연금으로 받으면 **퇴직소득세 감면**(수령 1~10년차 30%, 11~20년차 40%, 21년차~ 50%). 세액공제 받은 납입금+운용수익은 연금소득세(저율) 과세.

### 4.3 ISA (개인종합자산관리계좌)

| 항목 | 내용 |
|---|---|
| 유형 | **중개형**(직접 주식·ETF 매매, 가장 대중적) / 신탁형 / 일임형 |
| 납입 한도 | 연 **2,000만원**, 총 **1억원**(미납분 이월 가능) |
| 비과세 한도 | 일반형 200만원 → **2026 개정 500만원**(⚠️ 확정 재확인), 서민형 400만원 |
| 초과분 과세 | **9.9% 분리과세**(일반 이자·배당세 15.4%보다 유리) |
| 의무 보유 | 3년 |
| 연금 이전 혜택 | 만기자금을 IRP·연금저축으로 이전 시 **전환액 10%(최대 300만원) 추가 세액공제**. **해지 후 60일 이내** 이전 필수 |

> ⚠️ 2026 세법 개정(비과세 한도 상향 등)은 확정·시행 여부를 국세청/금융위 자료로 재확인.

### 4.4 절세 계좌 우선순위(일반 원칙)
1. DC/IRP·연금저축 세액공제 한도(900만원) 우선 소진 → 즉시 확정 수익(13.2~16.5%).
2. ISA 납입(비과세·분리과세) 활용, 만기 시 연금 이전으로 추가 공제.
3. 남는 자금은 일반 위탁계좌.

## 5. 기능 요구사항 (Functional Requirements)

### FR1. 제도 지식 베이스
- 4장의 제도·세제 데이터를 구조화해 저장(`rules` 테이블: 항목, 값, 근거, 갱신일).
- 사용자가 "IRP 한도?", "ISA 연금 이전 조건?" 질의 시 근거·출처와 함께 응답.

### FR2. 생애주기 가이드 엔진 (연령대별)
- 입력: 나이(또는 은퇴까지 남은 연수), 위험성향, 현재 자산.
- 출력: 목표 자산배분(주식/채권/현금/대체), 계좌 활용 우선순위, 체크리스트.
- **글라이드 패스** 규칙(은퇴까지 잔여연수 기반, 참고 경로):

| 시기 | 은퇴까지 | 목표 주식 비중(예시) | 초점 |
|---|---|---|---|
| **30대** | ~30년 | **80~90%** | 자산형성 초기. 복리 극대화, 세액공제 최대화, ISA 적극 납입. 손실도 시간이 회복 |
| **40대** | ~20년 | **65~75%** | 형성기 정점. 주택·자녀 병행, 분산 강화, 연금 납입 지속 |
| **50대** | ~10년 | **45~55%** | 보존기 전환(de-risking). 채권·배당↑, 퇴직금 IRP 이전 준비, 인출 계획 수립 |
| **은퇴 후** | 0 | **30~40%** | 인출기. 버킷 전략, 동적 인출, 절세 인출순서, 현금 2~3년 확보 |

> 참고 경로: 은퇴 30년 전 주식 80% → 10년 전 50% → 5년 전 40%. TDF의 글라이드 패스와 동일 개념.
> "너무 빨리 보수적"이면 인플레이션에 뒤처지므로 균형이 중요.

### FR3. 포트폴리오 검토·검증 (진단)
- 전 계좌(일반+DC/IRP+연금저축+ISA) 통합 뷰로 **현재 자산배분** 산출.
- 연령 기반 **목표 배분과의 이탈(드리프트)** 계산 → 초과/부족 자산군 표시.
- 기존 `portfolio_metrics`(HHI·집중도·손실종목 비중) + 자산군/계좌/통화/섹터 분산 진단.
- 세액공제 한도 소진율, ISA 한도 잔여, 위험자산 70%(IRP) 준수 여부 점검.

### FR4. 리밸런싱 엔진
- 방식(설정 가능): **밴드형**(목표 대비 ±5%p 이탈 시) 또는 **캘린더형**(분기/반기/연 1회).
- **세금 인지 리밸런싱**(핵심):
  - 매도 없는 조정 우선 → **신규 납입금(적립)으로 부족 자산군 매수**(현금흐름 리밸런싱).
  - 매도가 필요하면 **연금·ISA 계좌 내에서** 우선 실행(과세 이벤트 없음).
  - 일반계좌 매도는 최후, 손익통산·보유기간 고려.
- 출력: "무엇을 / 어느 계좌에서 / 얼마" 매수·매도 리스트 + 예상 세금·수수료.

### FR5. 절세 최적화 — 계좌 배치(Asset Location) & 인출 순서
- **자산 배치 규칙**: 세금 비효율(배당·이자·고회전) 자산은 **연금·ISA(절세계좌)**에,
  세금 효율(장기 성장·저배당) 자산은 일반계좌에 배치하도록 제안.
- **인출 순서 엔진(은퇴 후)**: 세부담 낮은 순서로 인출 플랜 생성.
  1. 세액공제 안 받은 원금(과세 제외) → 2. 퇴직금 이전분(연금수령한도 내, 퇴직소득세 30~40% 감면)
  → 3. 세액공제 받은 납입금+운용수익(연금소득세). 연금수령한도 초과분은 불리하므로 회피.

### FR6. 은퇴 인출 시뮬레이터
- **4% 룰**(Bengen) 기준선 + **동적 인출**(하락장 -5~10% 감액, 상승장 증액).
- **버킷 전략**: 단기(현금·단기채 2~3년 생활비) / 중기(채권·배당) / 장기(주식).
- **시퀀스 리스크** 경고: 은퇴 초반 하락장 대비 현금 버퍼 점검.
- 목표 월 생활비 → 필요 자산, 고갈 확률(몬테카를로) 산출.

### FR7. 대시보드·리포트
- 생애주기 목표 vs 현재 배분, 세액공제/ISA 진행률, 리밸런싱 제안, 은퇴 목표 달성 경로.
- 기존 매매 습관 리포트(손절·익절)와 통합된 단일 대시보드.

## 6. 데이터 모델 (기존 스키마 확장)

```sql
-- 계좌: 일반/DC/IRP/연금저축/ISA
CREATE TABLE accounts (
  account_id  TEXT PRIMARY KEY,
  type        TEXT,   -- 'general'|'dc'|'irp'|'pension_savings'|'isa'
  broker      TEXT,
  tax_wrapper TEXT,   -- 'taxable'|'tax_deferred'|'isa'
  opened_at   TEXT
);

-- holdings 에 account_id, asset_class 추가 (기존 확장)
ALTER TABLE holdings ADD COLUMN account_id TEXT;      -- accounts 참조
ALTER TABLE holdings ADD COLUMN asset_class TEXT;     -- 'equity'|'bond'|'cash'|'gold'|'reit'

-- 납입/세액공제 추적
CREATE TABLE contributions (
  account_id TEXT, year INTEGER, amount REAL,
  deductible INTEGER   -- 세액공제 대상 여부(1/0)
);

-- 생애주기 목표배분(글라이드 패스)
CREATE TABLE target_allocation (
  years_to_retire INTEGER,  -- 잔여연수 구간
  equity REAL, bond REAL, cash REAL, alt REAL
);

-- 제도·세제 규칙 (지식 베이스)
CREATE TABLE rules (
  key TEXT PRIMARY KEY, value TEXT, source TEXT, updated_at TEXT
);
```

리밸런싱·인출 로직은 이 테이블 + 기존 `portfolio_metrics`/`universe`를 조합해 계산.

## 7. 기존 프로그램과의 통합

- `holdings`·`portfolio_metrics`·`universe` **재사용**(계좌·자산군 컬럼만 확장).
- 매매 습관 분석(손절·익절)과 **동일 대시보드**에 생애주기·리밸런싱 탭 추가.
- 데이터 수집기(pykrx/FDR)로 ETF·채권·금 시세를 받아 자산군 평가에 활용.
- `sector.md` 유니버스에 **자산군 태그**(equity/bond/cash/gold/reit) 부여해 배분 계산에 연결.

## 8. 비기능 요구사항
- **정확성**: 세제 수치는 `rules`에 근거·갱신일과 함께 저장, 만료 시 경고.
- **투명성**: 모든 제안에 근거·가정·출처 표기(블랙박스 금지).
- **면책 고지**: 화면·리포트에 "투자·세무 자문 아님, 최신 세법 확인" 상시 노출.
- **프라이버시**: 계좌·자산 데이터는 로컬 저장(외부 전송 없음).

---

## 9. 로드맵 (마일스톤)

1. **M1 지식 베이스**: `rules`·`accounts`·제도 표 내장 + 질의 응답.
2. **M2 통합 포트폴리오 뷰**: 전 계좌 자산배분·드리프트·한도 소진율 진단(FR3).
3. **M3 생애주기 엔진**: 연령·잔여연수 기반 목표배분·체크리스트(FR2).
4. **M4 리밸런싱 엔진**: 세금 인지 리밸런싱 제안(FR4·FR5 배치).
5. **M5 은퇴 인출 시뮬레이터**: 4%·동적·버킷·인출순서·몬테카를로(FR5·FR6).
6. **M6 대시보드 통합**(FR7).

---

## 10. 리스크 & 가정
- **세법 변경 리스크**: 한도·비과세·공제율은 매년 바뀔 수 있음 → `rules` 갱신 루틴 필수.
- **상관 ≠ 인과 / 과거 ≠ 미래**: 글라이드 패스·4% 룰은 참고 기준, 강제 규정 아님.
- **개인차**: 위험성향·가족·부채·국민연금 수급 등은 별도 입력으로 조정.
- 투자·납입 실행은 사용자가 직접 수행(프로그램은 계산·제안까지).

## 12. 부록 B — 해외(미국) 배당 포트폴리오: "10억 → 월 300만원" 설계

> 흔히 말하는 "10억으로 월 300만원 배당 생활"을 해외(미국) 배당주·ETF로 설계하는 방법.
> **투자 권유가 아니라 설계 프레임워크**다. 배당률·수치는 조사 시점(2026-07) 참고치이며 변동한다.

### 12.1 목표 산수 (먼저 세금을 이해)

- 월 300만원 = **연 3,600만원**. 10억원 기준 **세전 배당수익률 3.6%** 면 도달.
- 그런데 세금이 두 번 붙는다:
  1. **미국 원천징수 15%**(한미조세조약, 일반 30%→15%). 배당의 85%만 입금.
  2. **한국 금융소득종합과세**: 연 이자·배당 **2,000만원 초과분은 종합과세**(다른 소득과 합산,
     누진세율). 3,600만원 배당은 2,000만원을 크게 넘으므로 **종합과세 대상**이 될 수 있다.
     (미국서 뗀 15%는 외국납부세액공제로 일부 상쇄)
- 따라서 **세전 3.6%로는 세후 월 300만원에 못 미친다.** 세후 월 300만원을 목표로 하면
  **세전 약 4.2~4.5%**(연 4,200~4,500만원) 또는 **절세 계좌 활용**이 필요하다.

### 12.2 절세의 핵심 — 어디에 담느냐 (계좌 배치)

- **일반계좌 + 해외상장 ETF(SCHD·JEPI 등)**: 15% 원천징수 + 2,000만원 초과 종합과세. 세금 부담 큼.
- **ISA + 국내상장 미국배당 ETF**: 배당이 ISA 내에서 비과세/9.9% 분리과세로 **종합과세 제외**.
  절세에 매우 유리. (단 ISA 납입 한도 연 2,000만·총 1억, 3년 보유)
- **연금저축/IRP + 국내상장 미국배당 ETF**: 배당 **과세이연**, 연금 수령 시 저율(연금소득세).
  단 만 55세 이후 연금 수령이라, **은퇴 전 '배당 생활'용으로는 부적합**(인출 제약).
- 실무 결론: **국내상장 '미국배당다우존스(SCHD형)' ETF를 ISA·연금에 우선 배치**하고,
  한도 초과분을 일반계좌에 두는 하이브리드가 세후 현금흐름에 가장 유리.

> 국내상장 미국배당 ETF 예(월배당·SCHD와 동일 지수 추종): **TIGER 미국배당다우존스,
> ACE 미국배당다우존스, KODEX 미국배당다우존스** 등(티커 ⚠️ 구현 시 재확인). S&P500 배당귀족,
> 미국채·리츠 국내상장 ETF도 조합 가능.

### 12.3 배당 자산 팔레트 (2026 참고 배당률)

| 자산 | 성격 | 참고 배당률 | 특징 |
|---|---|---|---|
| **SCHD**(미국배당다우존스) | 배당성장 | 약 3.3~3.5% | 10년 배당이력·재무우량 선별, 배당 연 10~12% 성장, NAV도 우상향 |
| VIG / DGRO | 배당성장 | 약 1.8~2.3% | 낮은 현재수익률·높은 성장·안정 |
| VYM | 고배당 | 약 2.8% | 광범위 고배당 대형주 |
| **JEPI**(S&P 커버드콜) | 고배당·월배당 | 약 8~8.5% | 옵션 프리미엄으로 월분배, **상승장 소외·NAV 성장 희생** |
| **JEPQ**(나스닥 커버드콜) | 고배당·월배당 | 약 10% | 나스닥 기반 커버드콜, 변동성·분배 변동 큼 |
| **O**(리얼티인컴, REIT) | 고배당·월배당 | 약 5.5% | 월배당 리츠, 금리 민감 |

### 12.4 3가지 아키타입 (10억 기준 예시)

**A. 배당성장형 (지속가능·자산도 성장) — 장기 최적**
SCHD 60% / DGRO 20% / VIG 20% → 블렌드 약 **2.8%** → 연 약 2,800만(월 233만) 세전.
지금은 월 300만에 못 미치지만 **배당이 연 8~10% 성장**하고 NAV도 올라 몇 년 뒤 월 300만 도달.
→ 은퇴까지 시간이 있으면 가장 건강한 방식.

**B. 고배당·월배당형 (즉시 현금흐름) — 지속성 주의**
JEPI 35% / JEPQ 25% / O 20% / SCHD 20% → 블렌드 약 **7.3%** → 연 약 7,260만(월 605만) 세전.
월 300만이면 **원금 약 5억으로도 가능**하지만, 커버드콜은 **상승장 소외·NAV/분배 잠식** 위험,
리츠는 금리 리스크. "높은 수익률"의 대가를 반드시 인지.

**C. 균형형 (세후 월 300만 목표)**
SCHD 45% / VYM 20% / JEPI 15% / JEPQ 10% / O 10% → 블렌드 약 **4.9%** → 연 약 4,915만(월 410만)
세전, 미국 15% 차감 후 월 약 348만 → 종합과세 감안해도 **월 300만 안팎** 확보. 성장+현금흐름 절충.

> 위 비중·수익률은 예시다. 실제로는 배당률·NAV·환율이 계속 바뀌므로 프로그램이 최신 데이터로
> 재계산해야 한다.

### 12.5 월배당 스케줄 조합 (매달 현금흐름 만들기)

- SCHD·VYM류: **분기 배당**(3·6·9·12월 등).
- JEPI·JEPQ·O·국내상장 미국배당 ETF: **매월 배당**.
- → 분기 배당주 + 월 배당 ETF를 섞으면 **12개월 고르게** 생활비가 들어오도록 설계 가능.

### 12.6 지속가능성 체크(리스크)

- **커버드콜 함정**: JEPI/JEPQ는 고분배지만 강세장에서 상승 제한, 장기 총수익·NAV가 배당성장형에
  뒤질 수 있음. "분배율=수익률"이 아니다.
- **배당 컷 리스크**: 개별 고배당주는 실적 악화 시 배당 삭감. ETF 분산으로 완화.
- **환율 리스크**: 배당은 달러, 생활비는 원화. 원/달러 하락 시 실수령↓ → 환헤지 or 원화 완충 필요.
- **인출 지속성**: 배당만으로 부족하면 원금 일부 인출 병행(4%·동적 인출 규칙과 연계).

### 12.7 프로그램 연동 (FR6 확장)

- **배당 캐시플로우 시뮬레이터**: 보유 배당자산×배당률×환율 → 월별 세전/세후 현금흐름 캘린더.
- **세금 엔진**: 미국 15% 원천징수 + 2,000만원 종합과세 임계 + ISA/연금 절세 반영해 **세후** 산출.
- **목표 역산**: "세후 월 300만원"을 넣으면 필요한 원금·블렌드 수익률·계좌 배치를 역산 제안.
- **지속성 경고**: 커버드콜 비중 과다·단일 종목 배당 의존·환노출 과다 시 경고 카드.

## 13. 부록 C — 노후 절세 & 건강보험료 최적화 (핵심)

> 노후 현금흐름의 실수령액은 **세금 + 건강보험료**가 좌우한다. 특히 건보료는 흔히 간과되는
> 최대 변수다. 아래 수치는 2026-07 조사 기준, 시행·개정 여부는 재확인 필요.

### 13.1 연금 수령 과세 (사적연금)

- **연령별 연금소득세(분리과세율, 지방세 포함)**: 만 55~69세 **5.5%**, 70~79세 **4.4%**, 80세~ **3.3%**.
  → 오래 살수록·늦게 받을수록 세율↓.
- **사적연금(연금저축·IRP) 연 1,500만원 기준(2024년 1,200만→1,500만 상향)**:
  - **1,500만원 이하**: 위 저율 분리과세로 종결(가장 유리).
  - **1,500만원 초과**: **종합과세(6~45%) vs 분리과세(16.5%)** 중 유리한 쪽 선택.
- **절세 원칙**: 연 수령액을 **1,500만원 이하로 분산**(수령 기간을 길게, 계좌 분산)하면
  저율 분리과세로 마무리 → 종합과세·고세율 회피.

### 13.2 공적연금(국민연금) 과세
- 2002년 이후 납입분에 대응하는 연금소득이 과세 대상(연금소득공제 적용). 사적연금과 **별도**로
  국민연금은 **건강보험료 산정에는 포함**(아래)되므로 주의.

### 13.3 건강보험료 — 노후의 숨은 최대 비용

은퇴 후 직장가입자에서 벗어나면 **피부양자**로 남거나 **지역가입자**로 전환된다.

**피부양자 자격(2026 기준)** — 하나라도 어기면 탈락:
- 연간 **합산소득 2,000만원 이하**(금융·근로·사업·연금·기타 합산).
- **금융소득(이자·배당)만 연 1,000만원 초과 시에도 탈락**.
- 재산세 과세표준 **5.4억원 이하**.
- 탈락 시 **지역가입자 전환 → 월 약 15~30만원** 본인 부담(소득·재산·자동차 점수제).
- 매년 11월 전년도 소득·재산으로 자격 재판정.

**결정적 포인트 — 소득 종류별 건보료 반영 차이**:

| 소득원 | 건보료(피부양자 판정) 반영 | 시사점 |
|---|---|---|
| **사적연금**(연금저축·IRP) | **제외**(산정에서 빠짐) | 건보료 관점 **최강 절세** 현금흐름 |
| 국민연금 등 공적연금 | **포함** | 연금소득에 합산 |
| 배당·이자(금융소득) | **포함**(단독 1,000만원 초과 시 탈락) | 배당 생활의 **숨은 비용** |

> **배당 생활의 함정(부록 B와 연결)**: 배당 3,600만원/년은 피부양자 소득 2,000만원·금융소득
> 1,000만원 기준을 모두 초과 → **피부양자 탈락·지역가입자 전환(연 180~360만원 건보료)**.
> 반면 같은 현금흐름을 **사적연금(연금저축·IRP)에서** 만들면 **건보료 산정 제외**. 그래서
> "배당 월 300만원"보다 "사적연금 + 일부 배당" 혼합이 세금+건보료 총비용에서 유리할 수 있다.

### 13.4 비과세 상품

- **비과세 종합저축**: 1인 **5,000만원까지 이자·배당 완전 비과세**(부부 각각 → 최대 1억).
  **건보료에도 미반영**. 단 **2026-01-01부터 대상이 '만 65세 이상 기초연금 수급자'로 축소**,
  직전 3년 내 **금융소득종합과세 대상자(2,000만원 초과)는 가입 불가**. → 자격되면 우선 활용.
- **ISA**: 3년 만기마다 재개설·반복해 비과세/분리과세(9.9%)로 금융소득을 종합과세에서 격리.
- **연금계좌(연금저축·IRP)**: 운용 중 과세이연 + 수령 시 저율 + 건보료 제외의 3중 이점.

### 13.5 종합과세·건보료 회피를 위한 분산 전략
- **부부 분산**: 계좌·자산을 배우자와 나눠 각자 금융소득 2,000만원·피부양자 임계 밑으로.
- **소득원 시기 분산**: 배당·연금 수령 시점을 분산해 특정 연도 종합과세 폭탄 회피.
- **계좌 우선순위(노후)**: 비과세종합저축 → ISA → 사적연금 → 일반계좌 순으로 과세소득을 격리.

### 13.6 프로그램 연동 (신규 요구사항)
- **FR8 건보료 시뮬레이터**: 소득원(공적연금·배당·이자·사업)별로 피부양자 유지 여부와
  지역가입자 예상 보험료를 계산. **금융소득 1,000만원·합산 2,000만원 임계 접근 시 경고**.
- **FR9 세후·건보 통합 현금흐름**: 세금 + 건보료를 모두 반영한 **실수령 월 현금흐름** 산출.
  "세후·건보 후 월 300만원" 목표로 필요한 소득원 구성을 역산.
- **FR10 소득원 배치 최적화**: 같은 목표 현금흐름을 **총비용(세금+건보료) 최소**가 되도록
  사적연금/배당/비과세저축에 배분 제안(부부 분산 포함).

## 14. 부록 D — 부동산 경매(지방 다가구) 월세 전략: 이자 제외 월 300~500만원

> 지방 소도시 다가구주택을 경매로 저가 매입해 월세 현금흐름을 만드는 방법. 실물·레버리지·
> 관리가 얽혀 있어 주식과 성격이 매우 다르다. 수치는 예시이며 지역·물건마다 크게 다르다.

### 14.1 왜 지방 경매 다가구인가
- 다가구주택은 **한 건물에 여러 세대**가 있어 **월세를 합산**해 큰 현금흐름을 만들 수 있다.
- 2026년 경매시장은 **지방이 수년째 호조**(수도권 지표 악화와 대비). 금리 여파로 **다가구·근린상가
  물건이 대거 공급**, 2회 이상 유찰 물건을 저가 낙찰할 기회. 전국 낙찰가율은 **80%대 중반** 수준.
- 1인 가구 증가로 **임대 수요가 탄탄한 입지**(역세권·산업단지·대학가 소형)가 관건.

### 14.2 현금흐름 산수 (예시, 이자 제외 순수입 관점)

| 항목 | 예시 A(현금) | 예시 B(레버리지) |
|---|---|---|
| 낙찰가(감정가 4억, 2회 유찰) | 약 3.0억 | 약 3.0억 |
| 대출 | 0 | 1.5억(연 4.5%) |
| 세대수 × 월세 | 7세대 × 45만 = **315만/월** | 315만/월 |
| 대출이자 | 0 | 약 -56만/월 |
| **이자 제외 순월세** | **약 315만** | 약 259만(자기자본 1.5억) |

- 월 **300~500만원**을 이자 제외로 얻으려면 대체로 **다가구 1~2채 / 자기자본 5~8억+** 필요.
- 순수익률(자기자본 대비)은 레버리지·공실·비용에 따라 크게 변동.

### 14.3 세금·건강보험료 (매우 중요)
- **다주택 판정**: 다가구주택은 세법상 단독주택(1채)이나, **본인 거주 주택이 별도면 다주택**이 되어
  월세 과세·건보료 부과 대상. 2주택은 월세 과세+건보료, 3주택↑은 **간주임대료**까지 과세.
- **임대소득**: 연 2,000만원 이하는 분리과세 선택 가능, 초과 시 종합과세. **연 2,000만원 초과
  소득은 건보료 추가 부과**(소득월액 보험료). 월세 300~500만원(연 3,600~6,000만원)은
  **종합과세·건보료 대상**이 될 가능성이 높다.
- **임대사업자 등록** 시 분리과세 필요경비율·공제·소형주택 세액감면 등 혜택(요건 충족 시).
- 취득세·재산세·종부세(다주택 중과 여부), 양도세도 별도 검토 필요.

### 14.4 리스크 (주식과 다른 점)
- **공실·연체**: 세대별 임대라 공실이 나면 현금흐름 직접 타격.
- **유동성 낮음**: 필요할 때 즉시 현금화 어려움(매각에 수개월~수년).
- **권리분석·명도 리스크**: 경매 특유의 선순위 임차인·명도(세입자 내보내기) 문제 → 전문성 필수.
- **관리 노동**: 수리·임차인 관리 등 **손이 많이 감**(주식의 '패시브'와 대조).
- **레버리지 양날**: 금리 상승 시 이자 부담↑, 순수입 급감.

### 14.5 장단점 요약
- **장점**: 큰 월 현금흐름, 실물 자산(인플레 방어), 레버리지로 자기자본수익률 제고, 시세차익 가능.
- **단점**: 낮은 유동성, 공실·관리·명도 리스크, 다주택 세금·건보료, 높은 초기자본·전문성.

## 15. 방법 비교 분석 — 지금까지 조사한 노후 현금흐름 방식

같은 "노후 월 현금흐름"이라도 성격이 크게 다르다. 아래는 본 문서에서 다룬 방식의 면밀 비교.

| 방식 | 기대수익/현금흐름 | 원금 변동성 | 유동성 | 인플레 방어 | 세금·건보료 | 관리 노력 | 초기자본 문턱 |
|---|---|---|---|---|---|---|---|
| **① 연금·ISA 인덱스/TDF**(자산증식) | 성장 중심, 인출로 현금화 | 중(주식비중) | 높음 | 좋음 | **최상**(과세이연·비과세, 건보 제외) | 낮음(자동) | 낮음 |
| **② 배당성장 ETF**(SCHD 등) | 현재 3%대, 배당 성장 | 중 | 높음 | 좋음 | 중(배당 종합과세·건보 반영) | 낮음 | 중 |
| **③ 고배당·커버드콜**(JEPI/JEPQ) | 7~10% 높은 분배 | 중~고(NAV 잠식) | 높음 | 약함 | 나쁨(금융소득·건보) | 낮음 | 중 |
| **④ 부동산 월세**(경매 다가구) | 월 300~500만 큰 현금흐름 | 저(시세 둔감)~레버리지 위험 | **낮음** | **좋음** | 나쁨(다주택 과세·건보) | **높음** | **높음** |
| **⑤ 사적연금 인출**(연금저축·IRP) | 안정적 월 수령 | 낮음(안전자산 비중) | 중(55세+ 제약) | 중 | **최상**(저율·**건보 제외**) | 낮음 | 중(적립 필요) |
| **⑥ 국민연금**(공적) | 종신 지급 | 없음 | 낮음 | 물가연동 | 과세·**건보 포함** | 없음 | 납입이력 |

**핵심 통찰**
- **세금+건보료까지 보면 순위가 뒤집힌다**: 고배당·부동산은 표면 현금흐름이 크지만
  **건보료·종합과세**로 실수령이 깎인다. **사적연금은 건보 제외라 실수령 방어가 가장 강하다.**
- **유동성·관리**: 주식·연금은 유동적·패시브, 부동산은 비유동·노동집약.
- **인플레 방어**: 실물(부동산)·주식 성장형이 강하고, 고정 분배(커버드콜)는 약하다.
- **결론적 원칙**: 단일 방식보다 **연금(절세·건보 방어) + 배당(현금흐름) + (성향 맞으면) 부동산
  (실물·인플레)**의 **혼합**이 리스크·세금·유동성의 균형을 만든다.

## 16. FR11 — 성향·자산유형 기반 노후설계 추천 엔진

### 16.1 입력 (프로파일링)
- 나이 / 은퇴까지 잔여연수, 총자산·유동자산 규모.
- **위험성향**(원금손실 수용도), **현금흐름 즉시성 필요**(지금 vs 나중).
- **관리 의향/노동 투입 가능**(부동산 관리·경매 학습 의지).
- **유동성 필요도**(급전 가능성), **소득 안정성 선호**(변동 싫음).
- 기존 자산 유형(현금·주식·부동산 편중도), 부부 여부(분산 활용).

### 16.2 추천 규칙(룰 매트릭스, 예시)

| 프로파일 | 특징 | 추천 조합 |
|---|---|---|
| **안정·저관리·유동성 중시** | 변동·손 가는 것 싫음 | 사적연금(코어) + 배당성장 ETF + 비과세저축. 부동산 지양 |
| **현금흐름 즉시·실물 선호·관리 가능** | 지금 월세 원함, 손품 OK | 경매 다가구 월세 + 배당 ETF 보완, 임대사업자 절세 |
| **성장 지향·장기·연령 젊음** | 시간이 자산 | 연금·ISA 최대납입 + 인덱스/배당성장(글라이드 패스) |
| **고령·현금흐름 최우선** | 실수령·건보 방어 중요 | 사적연금 분산수령(연 1,500만↓) + 비과세저축 + 소액 배당 |
| **자산 부동산 편중** | 유동성·집중 위험 | 일부 매각→연금·배당으로 분산, 건보·양도세 시뮬레이션 |
| **자산 현금 편중·인플레 우려** | 실질가치 방어 | 배당성장+실물(리츠/부동산) 단계 편입, 분할매수 |

### 16.3 출력
- 추천 **자산배분·계좌배치·소득원 구성**(세후·건보 후 목표 현금흐름 역산).
- 각 방식의 **장단점 카드**와 **내 프로파일 적합도 점수**(변동성·유동성·관리·세금 가중).
- 실행 체크리스트(연금 한도 소진, ISA 개설, 경매 권리분석 등)와 **리스크 경고**.

### 16.4 설계 원칙
- **정답 강요 금지**: 성향·제약에 따라 최적이 다르므로 **후보 2~3안**을 근거와 함께 제시.
- **총비용(세금+건보료+관리) 반영**: 표면 수익률이 아니라 **실수령·수고**까지 점수화.
- **분산 우선**: 한 방식 몰빵 경고, 혼합으로 리스크·세금·유동성 균형.
- 투자·세무 자문이 아니며, 실행 전 전문가·최신 세법 확인.
